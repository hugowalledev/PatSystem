# Mini Patient Management App

Fullstack application built with Node.js (Express) and Vue 3.

## Features

- List patients
- Create patient
- Update patient
- Delete patient
- View patient details

## Tech Stack

### Backend
- Node.js
- Express
- SQLite
- REST API
- Layered architecture (Controller / Service / Repository)
- Centralized error handling

### Frontend
- Vue 3
- Vite
- Vue Router
- Fetch API

## Project Structure

backend/
- controllers
- services
- repositories
- routes

frontend/
- components
- views
- router
- api
